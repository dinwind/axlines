# Review index

> **Role**: `.agent/project/review/` holds **formal review reports** (PR reviews, pre-release audits, design reviews, post-incident analyses).
> **Entry point for AI/MCP**: Always update this file when adding a review markdown so agents can discover it.
> **Not a substitute for**: `core/workflows/review-process.md` (process), `project/sop/code-review.md` (standing checklist), or SDD `changes/<name>/tasks.md` (execution).

## How to use

1. **Write** new reviews as `review/<subject>-<yyyy-mm-dd>.md` or `review/<kebab-name>.md`.
2. **Register** each review in the table below (path relative to `project/review/`).
3. **Read** this index before starting or answering "what reviews exist".
