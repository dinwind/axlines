# Project Conventions

> Coding conventions, style guidelines, and architecture decision records.

## Coding Conventions

This project is a VS Code fork. Conventions follow the upstream VS Code project:

- TypeScript strict mode where enabled
- ESLint configuration at `eslint.config.js`
- EditorConfig settings at `.editorconfig`

See upstream [CONTRIBUTING.md](../../CONTRIBUTING.md) for detailed guidelines.
